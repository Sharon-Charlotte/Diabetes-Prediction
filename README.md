# Data

This project uses the CDC 2021 Behavioral Risk Factor Surveillance
System (BRFSS) data.

Do not commit raw or restricted dataset files to this repository.
Document the dataset source, variables used, cleaning steps, and
any access or redistribution restrictions before publishing.
